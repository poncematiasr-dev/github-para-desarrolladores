# GitHub para desarrolladores

Repositorio con una introducción a **GitHub**, la plataforma para el desarrollo de software, la colaboración y la entrega. Se basa en Git, el sistema de control de versiones distribuido, y ofrece repositorios alojados en la nube junto con herramientas que cubren todo el ciclo de vida del software: planificación, codificación, revisión, seguridad, automatización y despliegue.

Lo usan desarrolladores individuales, contribuidores de código abierto, estudiantes y grandes equipos de ingeniería.

## Conceptos clave

- **Repositorios (repos):** lugares centrales para guardar código, historial, documentación y recursos relacionados. Pueden ser públicos o privados.
- **Fundamentos de Git:** ramas (branches), commits, push/pull y merge. GitHub agrega una interfaz web, funciones de colaboración y alojamiento sobre el Git local.
- **Issues y Projects:** seguimiento de tareas, bugs, funcionalidades e hitos. Los Projects ofrecen tableros y tablas conectados al código.
- **Pull Requests (PRs):** proponer cambios, discutirlos, ejecutar comprobaciones y fusionarlos. Admiten PRs apilados (stacked) para dividir cambios grandes en piezas más fáciles de revisar.
- **Colaboración:** revisión de código, Discussions, notificaciones y gestión de organizaciones y equipos.

## Funcionalidades principales

| Categoría | Herramientas clave |
|-----------|--------------------|
| **Codificación e IA** | GitHub Copilot (sugerencias en línea, chat y agentes), app de Copilot, Copilot CLI, Codespaces (entornos de desarrollo en la nube) |
| **Control de versiones y colaboración** | Repositorios, ramas, PRs, búsqueda y visualización de código, GitHub Desktop, GitHub CLI |
| **Automatización y CI/CD** | GitHub Actions (flujos de build, test y deploy), Packages, webhooks, acciones del Marketplace |
| **Seguridad** | Dependabot, Code scanning (CodeQL), Secret scanning, Copilot Autofix, ramas protegidas y rulesets |
| **Planificación e insights** | Issues, Projects, gráficos e insights del repositorio |

## Novedades de 2026: entrega de software agéntica

GitHub avanza hacia los agentes de IA. Entre las novedades mencionadas:

- **App de GitHub Copilot:** superficie para dirigir agentes desde un issue o un prompt hasta la revisión y el merge, con una bandeja de entrada centralizada entre repos.
- **Copilot Fusion:** orquestación multi-modelo que selecciona y combina modelos según la tarea, equilibrando calidad, costo y velocidad.
- **Copilot projects y continuidad de sesión:** agentes trabajando en paralelo en varios repositorios, y una misma sesión que puede continuarse entre la app, VS Code, la CLI y la web.
- **Copilot code review:** revisiones con IA que señalan problemas accionables antes de la revisión humana.
- **Flujos agénticos y automatizaciones:** flujos impulsados por eventos o programados que pueden aprender de sus resultados.

Según el documento de origen, más del 40 % de los desarrolladores ya inicia PRs con agentes, manteniendo el control sobre la dirección, la revisión y la calidad.

## Cómo empezar

1. Crear una cuenta gratuita en [github.com](https://github.com).
2. Instalar Git y, opcionalmente, GitHub CLI o GitHub Desktop.
3. Crear un repositorio, clonarlo localmente, hacer cambios, commit y push.
4. Seguir las rutas de aprendizaje oficiales: "Hello World", el Git Handbook y la serie "GitHub for Beginners".
5. Probar Copilot (tiene nivel gratuito) y Codespaces.
